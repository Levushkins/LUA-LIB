1 – Введение
Lua - язык программирования расширений, разработан для поддержки общего процедурного программирования с возможностью описания данных. Lua также предлагает хорошую поддержку объектно-ориентированного, функционального и управляемого данными (data-driven) программирования. Lua предлагается как мощный и лёгкий встраиваемый скриптовый язык для любой программы, которая в этом нуждается. Lua реализован как библиотека, написан на чистом C, общее подмножетво стандартного C и C++.

Как язык расширений, Lua не имеет понятия 'главной' программы: он работает только как встроенный в основную программу клиент, встраивающая программа называется хост (host). Встраивающая программа может вызывать функции для запуска кусочков Lua кода, может писать и читать Lua переменные, может регистрировать C-функции чтобы вызывать их из Lua кода. Через использование С-функций Lua может быть расширен для решения различных задач, таким образом созданные адаптированные языки программирования имеют общую синтаксическую базу. Дистрибутив Lua включает простую хост-программу lua, которая использует библиотеку Lua для реализации полного независимого Lua интерпретатора, для интерактивного или пакетного использования.

2 – Базовые концепции

2.1 – Значения и типы
Lua динамически типизированный язык. Это означает, что значения не имеют типов; только значения. Язык не имеет определений типов. Все значения несут свой собственный тип.

В Lua существует восемь базовых типов: nil, boolean, number, string, function, userdata, thread и table.

Тип nil (нуль) имеет одно единственное значение, nil, его главное свойство это отличаться от любых других значений; обычно это означает отсутствие используемого значения.
Тип boolean (логический) имеет два значения: false (ложь) и true (истина). Оба nil и false означают false; любое другое значение означает true.
Тип number (число) представляет целые (integer) и вещественные (float) числа.
Тип string (строка) представляет неизменные последовательности байт.
Тип userdata (пользовательские данные) предназначен для хранения произвольных С данных в Lua переменных. Существуют два типа пользовательских данных: full userdata (полные пользовательские данные) - объект с блоком памяти, которым управляет Lua, и light userdata (лёгкие пользовательские данные) - простой С указатель.
Тип thread (поток) представляет независимый поток выполнения и используется для реализации сопрограмм (coroutine).
Тип table (таблица) реализует ассоциативные массивы, это значит, что массив может быть проиндексирован не только числами, но и любым Lua значением, кроме nil и NaN.

Таблицы, функции, потоки и пользовательские данные (userdata) - это объекты: переменные фактически не содержат их значений, только ссылки на них. Присвоение, передача параметров и возврат из функций всегда манипулируют ссылками на эти значения.

2.2 – Окружения и глобальное окружение
Любая ссылка на свободное имя (т.е., имя не связанное ни с каким определением) var синтаксически транслируется в _ENV.var. Кроме того, каждый кусок (chunk) компилируется в области внешней локальной переменной, называемой _ENV.
Любая таблица, используемая как значение переменной _ENV, называется окружение (environment).
Lua хранит особое окружение, называемое глобальное окружение. В Lua, глобальная переменная _G инициализируется тем же значением.

2.3 – Обработка ошибок
Lua код может явно сгенерировать ошибку, вызвав функцию error. Если вы нуждаетесь в перехвате ошибок в Lua, вы можете использовать pcall или xpcall для вызова функции в защищенном режиме.
При каждой ошибке, создается объект ошибки (также называемый сообщением об ошибке).

2.4 – Метатаблицы и метаметоды
Каждое значение в Lua может иметь метатаблицу. Эта метатаблица обычная Lua таблица, которая определяет поведение оригинального значения в определенных специальных операциях. Ключи в метатаблице это производные от имен событий; соответствующие им значения называются метаметоды.
'add': + операция.
'sub': - операция (вычитание).
'mul': * операция (умножение).
'div': / операция (деление).
'mod': % операция (остаток от деления).
'pow': ^ операция (возведение в степень).
'unm': - операция (одноместный минус).
'idiv': // операция (целочисленное деление).
'band': & операция (битовое И).
'bor': | операция (битовое ИЛИ).
'bxor': ~ операция (битовое ИЛИ-НЕ).
'bnot': ~ операция (битовое одноместное НЕ).
'shl': << операция (битовый сдвиг влево).
'shr': >> операция (битовый сдвиг вправо).
'concat': .. операция (конкатенация).
'len': # операция (длина).
'eq': == операция (равенство).
'lt': < операция (меньше).
'le': <= операция (меньше или равно).
'index': индексированный доступ table[key]. Случается когда table не таблица или когда key не существует в table.
'newindex': индексированное присваивание table[key] = value. Случается когда table не таблица или когда key не существует в table.
'call': операция вызова func(args). Случается когда Lua пытается вызвать значение, не являющееся функцией.

2.5 – Сборка мусора
Lua реализует пошаговый отмечающий-и-очищающий сборщик. Для контроля циклов очистки мусора используются два числа: пауза сборщика мусора и множитель шагов сборщика мусора.
Пауза сборщика мусора контролирует, как долго сборщик ждет перед началом нового цикла.
Множитель шагов сборщика мусора контролирует относительную скорость сборщика по отношению к скорости выделения памяти.

2.5.1 – Метаметоды сборки мусора
Вы можете установить метаметоды сборки мусора для таблиц и полных пользовательских данных. Эти метаметоды также называются деструкторы (finalizers). Объект отмечается на уничтожение, когда устанавливается для него метатаблицу, содержащую поле '__gc'.

2.5.2 – Слабые таблицы
Слабая таблица (weak table) - это таблица, элементы которой это слабые ссылки. Слабость таблицы контролируется полем __mode в её метатаблице. Если поле __mode содержит символ 'k', в таблице слабые ключи. Если поле __mode содержит 'v', в таблице слабые значения.

2.6 – Сопрограммы
Сопрограмма в Lua представляет независимый поток выполнения. Сопрограмма прерывает свое исполнение только явным вызовом функции yield (уступить).
coroutine.create: создает сопрограмму.
coroutine.resume: запускает или продолжает выполнение сопрограммы.
coroutine.yield: приостанавливает выполнение сопрограммы.

3 – Язык

3.1 – Лексические соглашения
Имена (идентификаторы) могут быть любой строкой из букв, цифр и подчеркиваний, не начинающейся с цифры.
Следующие ключевые слова зарезервированы:
and break do else elseif end false for function goto if in local nil not or repeat return then true until while

Литеральные строки могут быть ограничены одинарными или двойными кавычками. Управляющие последовательности: '\a', '\b', '\f', '\n', '\r', '\t', '\v', '\\', '\"', '\''.
unicode-символ UTF-8: \u{XXX}.
Длинные скобки: [[ ... ]], [=[ ... ]=].

Комментарии:
-- короткий комментарий
--[[ длинный 
комментарий ]]

Числовые константы: 3, 345, 0xff, 3.0, 3.1416, 314.16e-2, 0x0.1E, 0xA23p-4.

3.2 – Переменные
Три вида переменных: глобальные переменные, локальные переменные и поля таблиц.
Любое имя переменной предполагается глобальным, пока явно не определено локальным. Локальные переменные лексически ограниченные.
t[i] - индексирование в таблице.
var.Name - семантическое украшение для var['Name'].

3.3.1 – Блоки
Блок - это список выражений, которые выполняются последовательно: block ::= {stat}.
Явные блоки: do block end. Полезны для контроля за областью видимости.

3.3.2 – Куски
Единица компиляции называется куском (chunk). Кусок обрабатывается как тело анонимной функции с переменным числом аргументов.

3.3.3 – Присваивание
Lua позволяет множественные присваивания: stat ::= varlist '=' explist.
Сперва вычисляются все выражения и лишь затем выполняется присваивание.
x, y = y, x -- меняет местами значения x и y.

3.3.4 – Управляющие конструкции
while exp do block end
repeat block until exp
if exp then block {elseif exp then block} [else block] end
goto Name (передает управление на метку ::Name::)
break (завершает цикл)
return [explist] (возврат значений из функции)

3.3.5 – Конструкция For
Цифровой цикл for:
for v = e1, e2, e3 do block end
(от e1 до e2 с шагом e3).

Общий цикл for (через итераторы):
for var_1, ···, var_n in explist do block end

3.4.1 – Арифметические операторы
+: сложение
-: вычитание
*: умножение
/: деление (всегда дает float)
//: целочисленное деление (округляет к минус бесконечности)
%: модуль (остаток от деления)
^: возведение в степень (всегда дает float)
-: одноместный минус

3.4.2 – Битовые операторы
&: битовое И
|: битовое ИЛИ
~: битовое ИЛИ НЕ
>>: правый сдвиг
<<: левый сдвиг
~: одноместное битовое НЕ

3.4.4 – Операторы сравнения
== (равенство), ~= (неравенство), <, >, <=, >=.

3.4.5 – Логические операторы
and, or, not.
and: возвращает первый аргумент, если он false или nil, иначе второй.
or: возвращает первый аргумент, если он не false и не nil, иначе второй.

3.4.7 – Оператор длины
Оператор #. Для строк - число байт. Для таблиц - длина последовательности.

3.4.8 – Приоритет операторов (от меньшего к большему)
or
and
< > <= >= ~= ==
|
~
&
<< >>
.. (конкатенация)
+ -
* / // %
not # - ~ (одноместные)
^

3.4.9 – Конструкторы таблиц
a = { [f(1)] = g; 'x', 'y'; x = 1, f(x), [30] = 23; 45 }

3.4.10 – Вызовы функций
functioncall ::= prefixexp args
v:name(args) - украшение для v.name(v,args).
Хвостовой вызов: return functioncall.

3.4.11 – Определения функций
function f () body end
local function f () body end
Функции с переменным числом аргументов: function g(a, b, ...) end. Три точки (...) внутри функции - это vararg-выражение.

3.5 – Правила видимости
Локальная переменная видима с первого выражения после её определения до конца блока.
Локальная переменная, используемая внутренней функцией, называется upvalue.

4 – Программный интерфейс (API)

4.1 – Стек
Lua использует виртуальный стек для передачи значений из и в С. Элементы стека доступны по индексу: положительный (1 - дно) или отрицательный (-1 - вершина).

4.4 – C замыкания
Функция lua_pushcclosure позволяет ассоциировать C значения (upvalues) с C функцией. Доступ через макрос lua_upvalueindex(n).

4.5 – Реестр
Предопределенная таблица LUA_REGISTRYINDEX для хранения любых Lua значений в C.

5 – Вспомогательная библиотека
Функции с префиксом luaL_.
luaL_newstate: создает новое состояние.
luaL_openlibs: открывает стандартные библиотеки.
luaL_loadfile / luaL_dofile: загрузка/запуск файла.

9 – Полный синтаксис Lua

chunk ::= block
block ::= {stat} [retstat]
stat ::=  ‘;’ | 
	 varlist ‘=’ explist | 
	 functioncall | 
	 label | 
	 break | 
	 goto Name | 
	 do block end | 
	 while exp do block end | 
	 repeat block until exp | 
	 if exp then block {elseif exp then block} [else block] end | 
	 for Name ‘=’ exp ‘,’ exp [‘,’ exp] do block end | 
	 for namelist in explist do block end | 
	 function funcname funcbody | 
	 local function Name funcbody | 
	 local namelist [‘=’ explist]
retstat ::= return [explist] [‘;’]
label ::= ‘::’ Name ‘::’
funcname ::= Name {‘.’ Name} [‘:’ Name]
varlist ::= var {‘,’ var}
var ::=  Name | prefixexp ‘[’ exp ‘]’ | prefixexp ‘.’ Name
namelist ::= Name {‘,’ Name}
explist ::= exp {‘,’ exp}
exp ::=  nil | false | true | Numeral | LiteralString | ‘...’ | functiondef | prefixexp | tableconstructor | exp binop exp | unop exp
prefixexp ::= var | functioncall | ‘(’ exp ‘)’
functioncall ::=  prefixexp args | prefixexp ‘:’ Name args
args ::=  ‘(’ [explist] ‘)’ | tableconstructor | LiteralString
functiondef ::= function funcbody
funcbody ::= ‘(’ [parlist] ‘)’ block end
parlist ::= namelist [‘,’ ‘...’] | ‘...’
tableconstructor ::= ‘{’ [fieldlist] ‘}’
fieldlist ::= field {fieldsep field} [fieldsep]
field ::= ‘[’ exp ‘]’ ‘=’ exp | Name ‘=’ exp | exp
fieldsep ::= ‘,’ | ‘;’
binop ::=  ‘+’ | ‘-’ | ‘*’ | ‘/’ | ‘//’ | ‘^’ | ‘%’ | ‘&’ | ‘~’ | ‘|’ | ‘>>’ | ‘<<’ | ‘..’ | ‘<’ | ‘<=’ | ‘>’ | ‘>=’ | ‘==’ | ‘~=’ | and | or
unop ::= ‘-’ | not | ‘#’ | ‘~’
