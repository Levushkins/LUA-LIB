Lua 5.1 Справочное руководство
авторы: Роберту Иерузалимски, Луиш Энрике ди Фигейреду, Валдемар Селиш

1 – Введение
Lua — это язык программирования расширений, разработанный для поддержки общего процедурного программирования с возможностями описания данных. Он также предлагает хорошую поддержку объектно-ориентированного программирования, функционального программирования и программирования, управляемого данными. Lua предназначен для использования в качестве мощного и легкого скриптового языка для любой программы, которая в нем нуждается. Lua реализован как библиотека, написанная на чистом Си (то есть на общем подмножестве ANSI C и C++).

Будучи языком расширений, Lua не имеет понятия 'главной' программы: он работает только встроенным в хост-клиент, называемый встраивающей программой или просто хостом. Эта хост-программа может вызывать функции для выполнения фрагмента кода Lua, может записывать и читать переменные Lua и может регистрировать Си-функции для вызова из кода Lua. С помощью Си-функций Lua может быть дополнен для работы в самых разных областях, создавая таким образом специализированные языки программирования с общей синтаксической базой. Дистрибутив Lua включает пример хост-программы под названием lua, которая использует библиотеку Lua для создания полноценного автономного интерпретатора Lua.

2 – Язык
В этом разделе описываются лексика, синтаксис и семантика Lua. Другими словами, этот раздел описывает, какие токены являются допустимыми, как они могут быть объединены и что означают их комбинации.

2.1 – Лексические соглашения
Имена (также называемые идентификаторами) в Lua могут быть любой строкой из букв, цифр и знаков подчеркивания, не начинающейся с цифры. Идентификаторы используются для именования переменных и полей таблиц.

Следующие ключевые слова зарезервированы и не могут использоваться как имена:
and break do else elseif end false for function if in local nil not or repeat return then true until while

Lua — язык, чувствительный к регистру: and является зарезервированным словом, но And и AND — это два разных допустимых имени. По соглашению, имена, начинающиеся с подчеркивания, за которым следуют заглавные буквы (например, _VERSION), зарезервированы для внутренних глобальных переменных, используемых Lua.

Следующие строки обозначают другие токены:
+ - * / % ^ # == ~= <= >= < > = ( ) { } [ ] ; : , . .. ...

Литеральные строки могут быть ограничены соответствующими одинарными или двойными кавычками и могут содержать следующие Си-подобные управляющие последовательности: '\a' (звонок), '\b' (забой), '\f' (разрыв страницы), '\n' (новая строка), '\r' (возврат каретки), '\t' (горизонтальная табуляция), '\v' (вертикальная табуляция), '\\' (обратный слэш), '\"' (двойная кавычка) и '\'' (одинарная кавычка). Кроме того, обратный слэш, за которым следует настоящий перевод строки, приводит к появлению новой строки в строке. Символ в строке также может быть задан его числовым значением с помощью управляющей последовательности \ddd, где ddd — последовательность из трех десятичных цифр. Строки в Lua могут содержать любое 8-битное значение, включая встроенные нули, которые могут быть указаны как '\0'.

Литеральные строки также могут быть определены с использованием длинного формата, заключенного в длинные скобки. Мы определяем открывающую длинную скобку уровня n как открывающую квадратную скобку, за которой следуют n знаков равенства, а затем еще одна открывающая квадратная скобка. Открывающая длинная скобка уровня 0 записывается как [[. Литералы в этой форме могут занимать несколько строк, не интерпретируют никакие управляющие последовательности.

Пример пяти литеральных строк, обозначающих одну и ту же строку:
  a = 'alo\n123"'
  a = "alo\n123\""
  a = '\97lo\10\04923"'
  a = [[alo
  123"]]
  a = [==[
  alo
  123"]==]

Комментарий начинается с двойного дефиса (--) в любом месте вне строки. Если текст сразу после -- не является открывающей длинной скобкой, это короткий комментарий, который продолжается до конца строки. В противном случае это длинный комментарий, который продолжается до соответствующей закрывающей длинной скобки.

2.2 – Значения и типы
Lua — это динамически типизированный язык. Это означает, что переменные не имеют типов; типы есть только у значений. В языке нет определений типов. Все значения несут свой собственный тип.

В Lua восемь базовых типов: nil, boolean, number, string, function, userdata, thread и table.
- Nil — это тип значения nil, основное свойство которого — отличаться от любого другого значения; обычно оно представляет отсутствие полезного значения.
- Boolean — это тип значений false и true.
- Number представляет вещественные числа (числа с плавающей запятой двойной точности).
- String представляет массивы символов. Lua 8-битно чист: строки могут содержать любой 8-битный символ, включая встроенные нули ('\0').
- Userdata позволяет хранить произвольные Си-данные в переменных Lua. Этот тип соответствует блоку сырой памяти.
- Thread представляет независимые потоки выполнения и используется для реализации сопрограмм (coroutines).
- Table реализует ассоциативные массивы, которые могут индексироваться не только числами, но и любым значением (кроме nil). Таблицы могут быть гетерогенными.

Таблицы, функции, потоки и значения userdata являются объектами: переменные фактически не содержат этих значений, а только ссылки на них. Присваивание, передача параметров и возврат функций всегда манипулируют ссылками.

2.3 – Переменные
Существует три вида переменных в Lua: глобальные переменные, локальные переменные и поля таблиц. Любая переменная считается глобальной, если она явно не объявлена как локальная.

До первого присваивания значение переменной равно nil.

Для индексации таблицы используются квадратные скобки:
  var ::= prefixexp `[` exp `]`

Синтаксис var.Name является синтаксическим сахаром для var["Name"]:
  var ::= prefixexp `.` Name

Доступ к глобальной переменной x эквивалентен _env.x, где _env — окружение работающей функции.

2.4 – Операторы
2.4.1 – Чанки (Chunks)
Единица выполнения Lua называется чанком. Чанк — это просто последовательность операторов, которые выполняются последовательно.
  chunk ::= {stat [`;`]}

2.4.2 – Блоки
Блок — это список операторов; синтаксически блок совпадает с чанком.
Блок может быть явно ограничен:
  stat ::= do block end

2.4.3 – Присваивание
Lua допускает множественные присваивания:
  stat ::= varlist `=` explist
Пример обмена значений:
  x, y = y, x

2.4.4 – Управляющие структуры
  stat ::= while exp do block end
  stat ::= repeat block until exp
  stat ::= if exp then block {elseif exp then block} [else block] end

В условии ложными считаются только false и nil. Все значения, отличные от nil и false, считаются истинными (включая число 0 и пустую строку).

Оператор return используется для возврата значений из функции. Оператор break используется для прекращения выполнения цикла. Они могут быть написаны только как последние операторы блока.

2.4.5 – Оператор For
Цифровой for:
  for v = e1, e2, e3 do block end
Эквивалентен коду:
  do
    local var, limit, step = tonumber(e1), tonumber(e2), tonumber(e3)
    if not (var and limit and step) then error() end
    while (step > 0 and var <= limit) or (step <= 0 and var >= limit) do
      local v = var
      block
      var = var + step
    end
  end

Универсальный for работает через функции-итераторы:
  for var_1, ···, var_n in explist do block end

2.5 – Выражения
Любое выражение, заключенное в скобки, всегда возвращает только одно значение. Таким образом, (f(x,y,z)) — это всегда единственное значение, даже если f возвращает несколько значений.

2.5.1 – Арифметические операторы
Бинарные: + (сложение), - (вычитание), * (умножение), / (деление), % (остаток), ^ (возведение в степень). Унарный: - (отрицание).

2.5.2 – Операторы отношения
==, ~=, <, >, <=, >=.

2.5.3 – Логические операторы
and, or, not.
- and возвращает первый аргумент, если он ложен или nil, иначе возвращает второй.
- or возвращает первый аргумент, если он не ложен и не nil, иначе возвращает второй.

2.5.4 – Конкатенация
Оператор конкатенации строк обозначается двумя точками ('..').

2.5.5 – Оператор длины
Обозначается унарным оператором #. Длина строки — это количество её байт. Длина таблицы t — это любой целый индекс n, такой что t[n] не равно nil, а t[n+1] равно nil.

2.5.7 – Конструкторы таблиц
Выражения для создания таблиц:
  a = { [f(1)] = g; "x", "y"; x = 1, f(x), [30] = 23; 45 }

2.5.8 – Вызовы функций
  functioncall ::= prefixexp args
Вызов вида v:name(args) — это синтаксический сахар для v.name(v,args), при этом v вычисляется только один раз.

Вызов вида return functioncall называется хвостовым вызовом (tail call). Lua реализует правильные хвостовые вызовы: вызванная функция повторно использует запись в стеке вызывающей функции.

2.5.9 – Определения функций
Синтаксис:
  function ::= function funcbody
  funcbody ::= `(` [parlist] `)` block end

Синтаксический сахар:
  function f () body end  --> f = function () body end
  local function f () body end --> local f; f = function () body end

2.6 – Правила видимости
Lua — это язык с лексической областью видимости. Область действия переменной начинается с первого оператора после её объявления и длится до конца самого внутреннего блока, включающего объявление.

2.8 – Метатаблицы
Каждое значение в Lua может иметь метатаблицу. Метатаблица — это обычная таблица Lua, которая определяет поведение исходного значения при определенных специальных операциях. Мы называем ключи в метатаблице событиями (events), а значения — метаметодами (metamethods).

События метатаблиц:
- "add": операция +.
- "sub": операция -.
- "mul": операция *.
- "div": операция /.
- "mod": операция %.
- "pow": операция ^.
- "unm": унарный минус.
- "concat": операция конкатенации .. .
- "len": операция #.
- "eq": операция ==.
- "lt": операция <.
- "le": операция <=.
- "index": доступ по индексу table[key].
- "newindex": присваивание по индексу table[key] = value.
- "call": вызывается, когда Lua вызывает значение (как функцию).

2.10 – Сборка мусора
Lua выполняет автоматическое управление памятью. Используется инкрементный сборщик мусора типа mark-and-sweep. Управление осуществляется двумя числами: паузой сборщика и множителем шага.

2.11 – Сопрограммы (Coroutines)
Сопрограмма представляет собой независимый поток выполнения. В отличие от многопоточных систем, сопрограмма приостанавливает выполнение только путем явного вызова функции yield.
- coroutine.create(f): создает новую сопрограмму.
- coroutine.resume(co, ...): запускает или продолжает выполнение.
- coroutine.yield(...): приостанавливает выполнение.

3 – Прикладной программный интерфейс (C API)
Этот раздел описывает Си API для Lua — набор функций Си, доступных хост-программе для связи с Lua.

3.1 – Стек
Lua использует виртуальный стек для передачи значений в Си и обратно. Каждый элемент в этом стеке представляет значение Lua. Положительный индекс представляет абсолютную позицию в стеке (начиная с 1); отрицательный индекс представляет смещение относительно вершины стека (вершина имеет индекс -1).

3.3 – Псевдо-индексы
Псевдо-индексы используются для доступа к вещам, которые не находятся в стеке: окружение потока (LUA_GLOBALSINDEX), окружение функции (LUA_ENVIRONINDEX) и реестр (LUA_REGISTRYINDEX).

3.7 – Функции и типы
- lua_call: вызывает функцию.
- lua_pcall: вызывает функцию в защищенном режиме.
- lua_pushboolean: помещает логическое значение в стек.
- lua_pushcfunction: помещает Си-функцию в стек.
- lua_pushinteger: помещает целое число в стек.
- lua_pushnil: помещает nil в стек.
- lua_pushnumber: помещает число в стек.
- lua_pushstring: помещает строку в стек.
- lua_toboolean: преобразует значение в логическое.
- lua_tointeger: преобразует значение в целое число.
- lua_tolstring: преобразует значение в Си-строку.
- lua_tonumber: преобразует значение в число.

5 – Стандартные библиотеки
5.1 – Базовые функции
- assert(v [, message]): вызывает ошибку, если v ложно.
- collectgarbage(opt [, arg]): интерфейс к сборщику мусора.
- dofile(filename): открывает файл и выполняет его как чанк.
- error(message [, level]): завершает функцию и возвращает сообщение об ошибке.
- getfenv(f): возвращает окружение функции.
- ipairs(t): итератор для массивов.
- pairs(t): итератор для таблиц.
- pcall(f, arg1, ···): вызывает функцию в защищенном режиме.
- print(···): выводит значения в stdout.
- type(v): возвращает тип значения в виде строки.
- unpack(list [, i [, j]]): возвращает элементы таблицы как список значений.

5.3 – Модули
- module(name [, ···]): создает модуль.
- require(modname): загружает модуль.

5.4 – Работа со строками
- string.byte(s [, i [, j]]): числовые коды символов.
- string.char(···): создает строку из кодов.
- string.find(s, pattern): поиск шаблона.
- string.format(formatstring, ···): форматирование строки.
- string.gsub(s, pattern, repl): глобальная замена.
- string.len(s): длина строки.
- string.lower(s): перевод в нижний регистр.
- string.match(s, pattern): поиск совпадения.
- string.sub(s, i [, j]): получение подстроки.
- string.upper(s): перевод в верхний регистр.

5.5 – Работа с таблицами
- table.concat(table [, sep]): конкатенация элементов.
- table.insert(table, [pos,] value): вставка элемента.
- table.remove(table [, pos]): удаление элемента.
- table.sort(table [, comp]): сортировка.

5.6 – Математические функции
- math.abs, math.cos, math.sin, math.tan, math.sqrt, math.random, math.floor, math.ceil, math.pi.

5.7 – Ввод и вывод
- io.open(filename [, mode]): открывает файл.
- io.read, io.write: чтение и запись.
- file:close(): закрывает файл.

6 – Автономная Lua
Использование интерпретатора lua:
  lua [options] [script [args]]
Опции:
- -e stat: выполняет строку кода;
- -l mod: загружает модуль;
- -i: входит в интерактивный режим;
- -v: выводит информацию о версии.

8 – Полный синтаксис Lua
  chunk ::= {stat [`;`]} [laststat [`;`]]
  block ::= chunk
  stat ::= varlist `=` explist | functioncall | do block end | while exp do block end | repeat block until exp | if exp then block {elseif exp then block} [else block] end | for Name `=` exp `,` exp [`,` exp] do block end | for namelist in explist do block end | function funcname funcbody | local function Name funcbody | local namelist [`=` explist]
  laststat ::= return [explist] | break
