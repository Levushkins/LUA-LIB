[Общая характеристика языка]
Lua (лу́а, с порт. — «луна») — скриптовый язык программирования. Интерпретатор языка свободно распространяется с открытым исходным кодом на Си.

По идеологии и реализации язык Lua ближе всего к JavaScript, в частности, он также реализует прототипную модель ООП, но отличается Паскале-подобным синтаксисом и более мощными и гибкими конструкциями. Характерной особенностью Lua является реализация большого числа программных сущностей минимумом синтаксических средств. Так, все составные пользовательские типы данных (массивы, структуры, множества, очереди, списки) реализуются через механизм таблиц, а механизмы объектно-ориентированного программирования, включая множественное наследование — с использованием метатаблиц, которые также отвечают за переопределение операций.

Lua — это процедурный динамически типизированный модульный язык с автоматическим управлением памятью. Включает базовые элементы для поддержки функционального и объектного стилей программирования. Таким образом, язык можно считать мультипарадигменным. Встроенные средства параллельного программирования позволяют писать многопоточные программы только средствами языка, не обращаясь к API операционной системы.

[Синтаксис и лексика]
Синтаксис Lua в основном построен на основе поздних Паскале-подобных языков, таких как Модула-2 или Оберон. Формат записи текста — свободный, команды разделяются любыми пробельными символами. Допускается применение точки с запятой для разделения операций.

Идентификаторы могут состоять из букв, цифр и знаков подчеркивания, но они не могут начинаться с цифры или совпадать с одним из ключевых слов. Язык регистрозависимый.

Ключевые слова:
and, break, do, else, elseif, end, false, goto, for, function, if, in, local, nil, not, or, repeat, return, then, true, until, while.

[Типы данных]
В Lua восемь основных типов:
1. nil (неопределенный);
2. boolean (логический);
3. number (числовой);
4. string (строковый);
5. function (функция);
6. userdata (пользовательские данные);
7. thread (асинхронный поток);
8. table (таблица).

nil — тип значения nil [пустое значение], обозначает отсутствие пригодного значения.
boolean — значения false (ложь) и true (истина).
number — вещественные числа (double). С версии 5.3 добавлена возможность явного определения целого или вещественного формата.
string — массивы символов, неизменяемы. Могут содержать любые 8-битные символы, включая ноль ('\0').
function — полноправные объекты, допускающие присваивание и передачу в параметрах.
thread — сопрограммы.
userdata — представление внешних данных, предоставленных из кода на другом языке (C/C++).

[Операции]
Присваивание:
Допускается параллельное присваивание: x, y = y, x. Если значений меньше, чем переменных, последние получают nil.

Сравнение и логика:
Операторы: <, >, <=, >=, ==, ~= (неравенство).
Логические: and, or, not. nil и false — ложь, все остальное (включая 0 и "") — истина.
Эмуляция тернарного оператора: r = ( a < b ) and f(a) or f(b)

Арифметические операторы:
+, -, *, /, - (унарный), %, ^ (возведение в степень).
Все поддерживают вещественные операнды.

[Таблицы]
Таблица — динамический гетерогенный ассоциативный массив (ключ-значение). Ключами могут быть значения любых типов, кроме nil.

Примеры работы с таблицами:
-- Таблица общего вида:
empty = {}
empty[1] = 'первый'
empty['третий'] = 'третий'
empty[1] = nil -- Удаление элемента

-- Массив (индексация с 1)
days = {'понедельник', 'вторник'}

-- Запись (структура)
person = {tabnum = 123, fio = 'Иванов'}
name = person.fio

-- Множество
workDays = {['понедельник']=true, ['вторник']=true}

[Замыкания]
function makeaddfunc(x)
  return function(y)
    return x + y
  end
end
plustwo = makeaddfunc(2)
print(plustwo(5)) -- Выводит 7

[Метатаблицы и метаметоды]
Метатаблица хранит дополнительные метаданные типов и объектов (параметры и функции). Поля начинаются с двух подчёркиваний.

Пример переопределения сложения:
t1 = {1,2,3}
mt = {}
mt.__add = function(a, b)
             local res = {}
             for k in pairs(a) do res[k] = a[k] + b[k] end
             return res
           end
setmetatable(t1, mt)

Поле __index:
Вызывается, когда интерпретатор не находит элемент в таблице. Может ссылаться на другую таблицу или функцию. Используется для реализации наследования.

[Объектно-ориентированное программирование]
Понятия «класса» нет, описывается отдельный объект-таблица.
Синтаксический сахар: 'Объект:метод' автоматически передает получателя в параметр self.

Account = {
  balance = 0,
  credit = function (self, v)
    self.balance = self.balance - v
  end
}

function Account:debet(v)
  self.balance = self.balance + v
end

Account:debet(1000) -- self передается автоматически

[Реализация]
Lua имеет компилятор в исполняемый байт-код и виртуальную машину. Байт-код — это команды виртуального процессора с регистрами. Используется строковый пул для экономии памяти. Существует JIT-компилятор (LuaJIT).

[Примеры кода]
-- Факториал
function factorial(n)
  if n == 0 then
    return 1
  else
    return n * factorial(n - 1)
  end
end

-- Бесконечная таблица Фибоначчи с мемоизацией
fibs = { 1, 1 }
setmetatable(fibs, {
  __index = function(name, n)
    name[n] = name[n - 1] + name[n - 2]
    return name[n]
  end
})
