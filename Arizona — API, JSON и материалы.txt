Arizona — API, JSON и материалы

Подборка ссылок на API-эндпоинты, JSON-источники, библиотеки-обёртки, исходники и справочники,
связанные с проектом Arizona RP (Arizona Games): SA-MP (PC), Arizona Mobile, Rodina, Arizona V.

Дата сборки: 15.08.2026

ВАЖНО (прочитать перед использованием):
— У Arizona Games НЕТ открытого публичного API с документацией. Всё, что перечислено ниже в разделе
  «JSON-эндпоинты», — это внутренние адреса лаунчера/сайта, найденные сообществом. Они не документированы,
  могут в любой момент изменить формат, потребовать заголовки/авторизацию или быть закрыты.
— Ссылки собраны поиском по открытым источникам. Часть ресурсов (blast.hk, git.arizona-rp.com,
  bugtracker.arizona.games, apitest.arizona-rp.com) закрыта от прямого доступа при сборке подборки,
  поэтому структуру ответов эндпоинтов нужно проверять самостоятельно (curl / браузер / DevTools).
— Не спамьте запросами: у неофициальных эндпоинтов легко словить бан по IP. Кэшируйте ответ
  (10–60 секунд для онлайна более чем достаточно).

REST API форума (XenForo 2):

    https://forum.arizona-rp.com/api/

    Стандартный XenForo REST API. Неаутентифицированного доступа нет — нужен API-ключ
    из админки (Setup → Service providers → API keys), который администрация форума
    сторонним разработчикам не выдаёт. Именно поэтому сообщество работает через
    cookie-обёртки (см. раздел 3).
    Документация XenForo: https://xenforo.com/docs/dev/rest-api/

Как искать новые эндпоинты самостоятельно:
— Лаунчер Arizona на Electron: распаковать resources/app.asar (`npx asar extract app.asar out`)
  и грепнуть по `https://`.
— DevTools/прокси (mitmproxy, Fiddler) на лаунчере и на сайте — вкладка Network, фильтр XHR.
— В JSON-конфигах игры/патчей встречаются файлы вида arizona/NamedModels.json.

10. ПРАКТИКА: ЗАБИРАЕМ JSON ИЗ MOONLOADER
================================================================================

Синхронно (просто, но блокирует Lua-поток на время запроса — только внутри lua_thread):

```lua
local requests = require('requests')

local ONLINE_URL = 'https://arizona-ping.react.group/desktop/ping/Arizona/ping.json'

local cache = {data = nil, time = 0}

function getOnline(force)
    -- кэш на 30 секунд: неофициальные эндпоинты не любят частых запросов
    if not force and cache.data and os.clock() - cache.time < 30 then
        return cache.data
    end
    local ok, resp = pcall(requests.get, ONLINE_URL, nil, {
        headers = {['User-Agent'] = 'MoonLoader'}
    })
    if not ok then return nil, tostring(resp) end
    if resp.status_code ~= 200 then return nil, 'HTTP ' .. resp.status_code end

    local ok2, data = pcall(decodeJson, resp.text)
    if not ok2 then return nil, 'bad json: ' .. tostring(data) end

    cache.data, cache.time = data, os.clock()
    return data
end

function main()
    while not isSampAvailable() do wait(0) end
    lua_thread.create(function()
        local data, err = getOnline()
        if not data then
            sampAddChatMessage('Ошибка запроса: ' .. err, -1)
            return
        end
        -- структура ответа не документирована: сначала посмотрите её глазами
        print(encodeJson(data))
    end)
end
```

Асинхронно (не блокирует поток) — два рабочих подхода уже описаны в этом репозитории:
    «Асинхронные HTTP запросы в MoonLoader.txt» — copas + LuaSocket + LuaSec;
    «Автообновление с помощью requests.txt»     — requests + decodeJson + downloadUrlToFile.

Замечания:
— decodeJson / encodeJson встроены в MoonLoader; для сложных случаев берите dkjson или rapidjson
  (см. «Библиотеки MoonLoader.txt»).
— HTTPS через socket.http не работает — нужен LuaSec (ssl.https) либо requests.
— Всегда оборачивайте запрос и разбор JSON в pcall: упавший парсер уронит скрипт.
— Для игровых данных (баланс, депозит, AZ-коины) внешнего API нет вообще: их получают из диалогов
  и чата — см. «Эмуляция RPC, заполнение BitStream для кипятильников.txt» и раздел про
  sampRegisterChatCommand / OnShowDialog в «Полезные сниппеты и функции.txt».

11. ПРЕДОСТЕРЕЖЕНИЯ
================================================================================

— Эндпоинты из раздела 2 неофициальные: их закрывали и меняли уже не раз. Пишите код так,
  чтобы отвал источника не ломал скрипт (таймауты, pcall, фолбэк на SA-MP query).
— Cookie-авторизация (arz-api) = полный доступ к вашему форумному аккаунту. Не храните куки
  в открытом виде в скрипте и не выкладывайте их в репозиторий.
— Массовый парсинг сайта (mon/fraction, профили) быстро приводит к блокировке IP.
  Ставьте паузы, кэшируйте, не опрашивайте чаще, чем реально нужно.
— Правила проекта запрещают автоматизацию игрового процесса. Мониторинг, статистика и
  информационные скрипты — безопасная зона; авто-игра — нет.
